# Security Policy

## Supported Versions

| Version | Supported |
|---------|-----------|
| latest  | ✅        |

Only the latest release receives security fixes. We recommend always using the most recent version.

## Reporting a Vulnerability

**Please do not open a public GitHub issue for security vulnerabilities.**

Report security issues privately via GitHub's built-in
[Security Advisories](https://github.com/lemon4ksan/ctrl/security/advisories/new)
feature (Security → Advisories → New draft advisory).

Include as much of the following as you can:

- A description of the vulnerability and its potential impact (e.g. CLI argument injection, terminal escape sequence injection, memory corruption)
- Steps to reproduce (code snippet, harness, or terminal reproduction)
- The version of `ctrl` and Go you are using
- Any relevant environment details (OS, CPU architecture, terminal emulator)

We will acknowledge receipt within **72 hours** and aim to release a fix within
**14 days** for confirmed critical issues.
